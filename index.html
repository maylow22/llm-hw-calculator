    API roste s každým měsícem provozu, vlastní HW začíná pořizovací cenou a pak roste jen o provoz. Průsečík je bod návratnosti.

    Cena API za token je stálá, vlastní HW s objemem zlevňuje. Schody jsou dokoupení dalšího kusu; křivka HW končí tam, kde stroj nestačí ani s maximálním počtem kusů.

    Všechny stroje pro zadanou spotřebu a model. Kliknutím na řádek stroj vybereš.

    Výchozí ceny k (API ceníky, ČNB kurz, ceny HW v USD). Propustnost strojů je hrubý odhad pro referenční open-weight model; kvalita lokálního modelu se od API modelu liší. Orientační výpočet, ne nabídka.
